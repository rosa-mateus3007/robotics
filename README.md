# 🤖 Robótica e Automação

Repositório com projetos de robótica e automação desenvolvidos com Arduino Uno. Aqui você vai encontrar projetos com sensores, displays e sistemas simples de automação, com código em C++ e simulações no Tinkercad.

## Objetivo

O objetivo deste repositório é:
- praticar e melhorar habilidades em programação C++ para Arduino;
- simular circuitos antes de montar no mundo real;
- organizar projetos de robótica de forma clara;
- documentar circuitos e componentes utilizados;
- criar um portfólio com projetos funcionais.

## Tecnologias e plataformas utilizadas

- **Arduino Uno** - placa microcontroladora
- **C++** - linguagem de programação
- **Tinkercad** - simulador de circuitos e Arduino
- **GitHub** - versionamento de código

## Componentes disponíveis

- LEDs (RGB e monocromáticos)
- Botões e chaves
- Resistores
- Sensor de distância (ultrassônico)
- Display de 7 segmentos
- LCD 16x2
- Protoboard
- Fios de conexão
- Fonte de alimentação
